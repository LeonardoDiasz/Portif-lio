# Portfólio profissional

Portfólio de **Leonardo Dias**, estudante de Ciência da Computação, desenvolvido com HTML5 e CSS3.

## Sobre o projeto

Este projeto foi criado na disciplina **Design Profissional** (Projeto 2: publicação do portfólio profissional e do currículo no GitHub). O site apresenta meu perfil, minha formação, minhas competências e meu projeto, e é publicado gratuitamente no GitHub Pages.

O visual é inspirado em uma arte em preto, branco e vermelho, com vértebras de uma centopeia gigante e flores higanbana. As molduras vermelhas dos cartões vêm da caixa central dessa arte.

## Objetivos

- Apresentar meu perfil profissional de forma clara e verdadeira.
- Praticar estrutura com HTML5 e estilização com CSS3.
- Praticar o uso de Git e GitHub: commits, branch, pull request e publicação.
- Disponibilizar o currículo e meus links profissionais em um só lugar.

## Tecnologias utilizadas

- HTML5 (estrutura semântica)
- CSS3 (Flexbox, Grid e layout responsivo)
- Imagens locais
- Git e GitHub
- GitHub Pages

Não foram usados frameworks, JavaScript, banco de dados nem formulários.

## Estrutura do portfólio

```
portfolio-profissional/
|-- index.html      # conteúdo e estrutura da página
|-- style.css       # cores, fontes, layout e responsividade
|-- README.md       # documentação do projeto
|-- LICENSE         # licença (a definir)
`-- assets/
    |-- foto-perfil.jpg   # foto de perfil
    |-- fundo.png         # arte usada no cabeçalho e no cartão do projeto
    `-- curriculo.pdf     # currículo (será adicionado)
```

Seções da página: cabeçalho com menu, apresentação, Sobre mim, formação e cursos, competências técnicas, competências comportamentais, projetos, currículo, contato e rodapé com autoria.
